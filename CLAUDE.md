## Project Summary

Read project_management/manifest.md.

Javelin Idle is a browser-based idle/clicker game (currently vanilla JS, HTML, CSS) built to help the developer practice stenography key combinations for common programming symbols. The player types displayed symbol sequences to earn score, purchases upgrades that auto-generate score over time, and unlocks new character sets as the game progresses. Game state is saved to localStorage or exported as a JSON string for manual backup.
